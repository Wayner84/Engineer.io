# Engineer.io project rules

- Build a complete, polished browser factory game matching `docs/PRODUCT_SPEC.md`.
- Use TypeScript + Vite. Keep simulation deterministic and testable outside the DOM.
- GitHub Pages project URL requires Vite base `/Engineer.io/` in production.
- Use original geometric/industrial visuals; do not copy Factorio assets, names, UI, or text.
- Industrial visual language: dark graphite surfaces, engineering-blue interactions, amber warnings, green good-quality state, sharp geometry, readable dense controls.
- Never commit secrets or user-specific files.
- Run tests, typecheck, and production build before claiming completion.
- Do not push, force, reset, clean, or rewrite history unless the orchestrator explicitly requests it.
